# AIMAR Command Deck

Interactive public demo for AIMAR Systems Group.

AIMAR stands for Applied Intelligence Mainframe, Automation, and Research.

This command deck presents AIMAR as operational intelligence infrastructure: workflows, memory systems, dashboards, security-aware automation, governance, research, signal processing, and execution support.

## Public-facing posture

This repository is designed as a sendable public demo. All data shown in the interface is sample data.

Do not commit secrets, credentials, private client data, internal runbooks, or production infrastructure details.

## Core doctrine

- systems over hype
- workflow before tool
- governance before scale
- read-only before write-back
- modular systems over monoliths
- human judgment remains central
- operational usefulness over novelty
- security, compliance, and OPSEC by default
